# DSH 多开器（dsh-instance-manager）

给 DSH 加一个「多开器」面板：在本机开多份**完全独立**的 DSH，像手机模拟器多开一样。
每份 DSH 都有自己的配置、插件、账户、会话和权限，和装了一个全新的 DSH 一样。

## 功能

- 左栏「多开器」：本机所有 DSH 的总控台，当前窗口也在列表里（只读）。
- 新建多开：命名，选择「网页版」或「Windows 桌面版」。
- 启动 / 停止 / 重启 / 打开 / 删除。
- 多选批量启动、停止、删除。
- 复制实例：复制配置与插件清单到一份新实例（不复制会话、登录、文件和运行数据）。
- 每个多开出来的 DSH 也自带多开器，所有面板共享同一份实例列表。
- 权限沿用原生 DSH 的会话设置（工作区内修改 / 完全权限 / 仅可查看），不在多开器里锁死。

## 安装

要求：DSH 桌面版 0.2.2-rc.1 或更新。

方式 A（推荐）：把 `dsh-instance-manager` 文件夹放到任意目录，在 DSH 的「插件」页用本地文件夹安装（选择这个文件夹）。

方式 B（命令行）：在能运行 `dsh` 的终端里：

```powershell
dsh plugin --profile desktop add "link:D:/path/to/dsh-instance-manager"
```

方式 C（GitHub Release）：从仓库的 Releases 下载 `dsh-instance-manager-*.zip`，解压后按方式 A 安装。

装完后重启一次 DSH，或在插件页把本插件禁用再启用，让 bundle 生效。
本插件零第三方依赖，不需要联网安装依赖。

## 使用

1. 左栏点「多开器」。
2. 点「新建多开」，输入名称，选平台，创建。
3. 卡片上点「启动」：
   - 网页版：自动用默认浏览器打开，独立端口。
   - Windows 桌面版：出现一个独立窗口，关窗会收进系统托盘。
4. 运行中可「打开 / 重启 / 停止」，停止后可删除。

## 数据在哪

- 开发/绿色目录布局：`<插件所在目录>/../../instances`
- 正常安装布局：`<DSH_HOME>/dsh-multi/instances`（默认 `C:\Users\<你>\.dsh\dsh-multi\instances`）

每个实例一个目录，里面有 `profiles/`、`sessions/`、`workspace/`、`web.log`。
删除实例 = 删除整个目录，请先停止。

## 注意

- Windows 桌面版多开依赖 Electron 的独立 `userData`，插件已自动处理；本插件目前只在 Windows 上验证过。
- 首次启动一个全新的桌面实例，会看到 DSH 原生的欢迎页（登录 DeepSeek 账号，或添加 API Key），行为与原生 DSH 完全一致。
- 当前窗口（运行这个面板的 DSH）是只读的：不能停止/删除自己。
- 实例名称会作为目录名，避免使用 `\ / : * ? " < > |`。

## 安全说明

本插件会在这台电脑上创建、启动、停止 DSH 进程，并读写实例目录；它不读取账号凭据，也不会把 API Key 写入磁盘或日志（API Key 只通过子进程环境变量传递）。请只从可信来源安装本插件。
